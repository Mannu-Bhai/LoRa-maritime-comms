# LoRa-maritime-comms
Low-cost off-grid LoRa communication for small fishing fleets beyond cellular coverage.
The name of the project is RelayDrop.
A fishing boat goes too far from shore and loses cellular signal. RelayDrop lets the crew keep using a phone to send short messages.  
The phone talks to a small box on the boat. That box sends the message over LoRa to another boat, then another, until it reaches shore.  
Think of it like passing a note from boat to boat until it gets back to land.
